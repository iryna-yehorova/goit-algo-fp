# goit-algo-fp

Фінальний проєкт із семи завдань з алгоритмів і структур даних. Для завдань
1–3, 6 і 7 достатньо Python 3. Завдання 4 і 5 використовують `matplotlib`
та `networkx`:

```bash
python3 -m pip install -r requirements.txt
```

## Завдання 1. Однозв'язний список

Файл `task_1.py` містить клас `LinkedList` і три операції:

- `reverse()` розвертає список, змінюючи посилання між вузлами;
- `sort()` сортує список за зростанням методом злиття;
- `merge_sorted_lists(left, right)` зливає два відсортовані списки в один.

Операції використовують наявні вузли. Після злиття вхідні списки порожні,
оскільки їхні вузли переходять до результату. Приклад роботи:

```bash
python3 task_1.py
```

## Завдання 2. Рекурсивне дерево Піфагора

Файл `task_2.py` рекурсивно обчислює гілки фрактала й малює їх символами
безпосередньо в консолі. Рівень рекурсії можна вказати від 0 до 10:

```bash
python3 task_2.py 5
```

Якщо не вказати рівень у команді, програма запитає його після запуску.
Розмір малюнка можна змінити аргументами `--width` і `--height`.

## Завдання 3. Алгоритм Дейкстри

Файл `task_3.py` реалізує зважений граф і пошук найкоротших шляхів від
початкової вершини. Бінарна купа `heapq` допомагає вибирати наступну
вершину. Функція `dijkstra(graph, start)` повертає відстані та попередників,
а `shortest_path(...)` відновлює маршрут. Приклад обчислює шляхи від `A`
до всіх вершин; для недосяжної `G` відстань дорівнює нескінченності.

```bash
python3 task_3.py
```

## Завдання 4. Візуалізація бінарної купи

Файл `task_4.py` перетворює масив мін-купи на бінарне дерево за індексами
дітей `2i + 1` та `2i + 2`, після чого малює його за допомогою
`networkx` і `matplotlib`. Перед побудовою задані числа впорядковуються
функцією `heapq.heapify`.

```bash
python3 task_4.py 12 4 15 2 9 7 20
```

Для збереження статичного зображення додайте `-o heap.png`.

## Завдання 5. Обходи дерева DFS і BFS

Файл `task_5.py` будує дерево з купи та показує поруч результати двох
обходів: DFS використовує стек, BFS — чергу. Кожен вузол отримує унікальний
колір у форматі `#RRGGBB`: від темного для відвіданих раніше до світлого
для відвіданих пізніше. Результат є статичним зображенням.

```bash
python3 task_5.py 12 4 15 2 9 7 20
```

Для збереження зображення додайте `-o traversals.png`. Порядок обходів
також друкується в консолі.

## Завдання 6. Вибір страв у межах бюджету

Файл `task_6.py` порівнює два способи вибору страв, кожну з яких можна
взяти лише один раз. `greedy_algorithm(items, budget)` послідовно обирає
страви за співвідношенням калорій до вартості. `dynamic_programming(...)`
розв'язує задачу 0/1-рюкзака й знаходить набір із максимальною сумарною
калорійністю в межах бюджету.

```bash
python3 task_6.py 100
```

За бюджету 100 жадібний алгоритм дає 870 калорій за 80 одиниць вартості,
а динамічне програмування — 970 калорій за 100. Це показує, що локальний
вибір за найкращим співвідношенням не завжди дає глобальний оптимум.

## Завдання 7. Метод Монте-Карло для двох кубиків

Програма `task_7.py` імітує кидки двох шестигранних кубиків, підраховує
частоти сум від 2 до 12 та порівнює їх із точними ймовірностями.

Запуск із відтворюваним результатом:

```bash
python3 task_7.py 1000000 --seed 42
```
